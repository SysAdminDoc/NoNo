# BuzzKill Notification Manager clean-room audit

This directory is the evidence-backed black-box reconstruction blueprint for BuzzKill Notification Manager (`com.samruston.buzzkill`) version 36.0.0. The audit used the operator-supplied `BuzzKill v36.0.0.apk` in an isolated, headless Android 16 emulator controlled through ADB. No replacement app, Android source, Gradle project, layout, Compose screen, or replacement asset was created.

## Scope and evidence rules

- Native BuzzKill behavior is the reconstruction scope.
- Android permission/settings surfaces are cataloged as external system dependencies.
- Chrome handoffs are cataloged but not treated as native screens.
- LiteAPKS promotional overlays embedded by the supplied distribution artifact are marked `excluded_repackaging` and are excluded from native screen counts, tokens, component design, and reconstruction requirements.
- Findings use `CONFIRMED`, `STRONG INFERENCE`, `POSSIBLE`, or `UNKNOWN`.
- Every screen capture has a PNG, UI hierarchy, activity/window evidence, metadata, and a row in `evidence/evidence-manifest.csv`.
- The only app record created is a clearly named test rule containing `AUDIT_SENTINEL_8675309`; it was disabled immediately. The only history record was generated by Android's Shell notification command and contains no personal data.

## Capture utilities

PowerShell scripts under `scripts/` support explicit serial selection, validate ADB/device state, create missing evidence directories, check exit codes, and refuse to overwrite evidence. They are compatible with Windows PowerShell 5.1 syntax. Example:

```powershell
.\scripts\capture-screen.ps1 -ScreenId 100_example_state -Serial emulator-5554 -AdbPath D:\tools\android-sdk\platform-tools\adb.exe
```
