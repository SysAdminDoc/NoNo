# Remaining implementation backlog

The following work is intentionally not represented as complete:

1. **Original identity and artwork** — requires explicit authorization and files under `authorized-assets`; otherwise the independent Signal Rules identity must remain.
2. **Onboarding/Explore pixel refinement** — nine states remain below the project's 0.85 comparison threshold because independently written copy and artwork occupy different pixels.
3. **Preferred 0.985 visual target (retired)** — the target is withdrawn because identity artwork and editorial copy are unauthorized clean-room substitutions. Per-screen thresholds remain the measurable gate.
4. **Production notification action engine** — audited actions are configurable but intentionally simulated; real mute, dismiss, reply, Tasker, MacroDroid, batch, and device-control side effects need separate product authorization and specifications.
5. **Backup and shortcut effects** — implement a new documented file format, actual import/export/automatic backup repository, and `ShortcutManager` publication after product decisions are supplied.
6. **Exact proprietary font/custom icon geometry** — requires authorized font/icon files or further independent vector refinement.
7. **Unsafe or unobserved branches** — destructive delete-all, real restore/open/reply actions, permission-denial branches, and external web contents remain blocked, simulated, or untested as recorded in the audit.

These items are why the delivery is classified as partially complete rather than an exact replica.
